# Issue #56：翻页与自动阅读

来源：https://github.com/Cheese-nya/uku-furigana/issues/56

## 已实现（公开版 1.8.4 源码、云同步版 2.0.4 源码）

两版采用相同的阅读导航核心；未调整版本号、发布安装包、部署服务或关闭 issue。

- 保留连续滚动。侧边翻页默认开启，左右各 20% 优先翻页；横排右侧下一屏，竖排左侧下一屏，中间继续查词与显隐工具栏。
- 每次按当前轴可视长度的 90% 翻动；章末／章首再次翻页进入下一章开头／上一章末尾，书首书末不循环。约 200 ms 过渡期间合并重复输入；减少动态效果时直接定位。
- 拖动超过 10 px、500 ms 以上长按、取消触摸、文本选择、按钮及弹层不触发侧边翻页。
- 自动阅读分连续滚动（10–100 px/s，默认 30）与定时翻页（3–60 秒／屏，默认 10）。滚动模式章末停留 1.5 秒再跨章；定时模式每次完成翻页后完整重新计时。短章也保留停留时间，书末停止。
- 手动操作暂停；排版、目录、查词、翻译拖动及位置恢复期间挂起。切书、退出阅读器或进入后台停止，回来不自动运行。自动阅读期间胶囊保持可见，便于暂停。
- 阅读偏好继续使用 `furigana_reader_prefs_v3`，兼容旧记录，校验模式和数值；保存侧边开关、音量键开关、自动模式、速度和间隔。偏好仅本机保存，运行状态不持久化。
- Android 音量键翻页默认关闭，仅新原生桥存在时显示开关。开启后正文可交互时，音量上上一屏、音量下下一屏；弹层、选择文本、后台、退出、页面重载时恢复音量行为。长按不连翻，消费的 DOWN 配对消费 UP；新按压可清理失焦遗留的按下标记。
- 工作台预览页起始行变化时在绘制前归顶，搜索／校对显式定位随后执行；两版均保留此修复。

## 代码入口与接口

- `readerNavigation.ts`：翻页目标、侧边方向和完整手势判定。
- `useReaderNavigation.ts`：统一翻页入口、运动锁、自动阅读调度、弹层／前后台状态及原生启用策略。
- `autoReading.ts`：连续滚动与定时翻页调度，包含取消及挂起处理。
- `AndroidBridge.setReaderVolumeKeysEnabled(boolean)`；原生发送 `uku-reader-page-turn`，`detail.direction` 为 `previous`／`next`。原生焦点／后台通过 `uku-reader-native-focus` 的 `detail.active` 通知页面。
- 跨章定位在过渡期间跟随章节边界，处理 `content-visibility` 延迟布局产生的高度估算变化；保留翻译重排锚定。

## 验证结果

- 公开版：685 项测试，684 通过、1 跳过、0 失败。
- 云同步版：734 项测试，733 通过、1 跳过、0 失败。
- 两版类型检查及生产构建通过。
- 两版 Lint 均无错误；公开版 1 条原有警告，云版 19 条原有警告（部署目录 JS 和 nameReadings 测试）。
- Android 两版使用 JDK 17、Android 33 API、Java 11 目标编译通过；仅有原有 API 弃用提示。
- Chromium 生产构建两版实测：390 px 手机布局、真实浏览器触摸点击、拖动回到起点与长按排除、横／竖排方向、前后跨章和短章、减少动态效果、两种自动模式、手动暂停、面板挂起、书末停止、重新进入不自动运行、速度和音量键偏好恢复、桥接启停、原生前后台事件。
- 两版 `check-reader-translation.mjs` 回归通过：翻译开关、异步译文到达、横竖排字符位置保持在 3 px 内、触摸期间延后发布、悬浮按钮拖出／收回、键盘移动、旋转和持久化；无页面错误。此专用测试关闭侧边翻页，避免其既有的边缘点击显隐工具栏步骤变成翻页；侧边行为由导航测试独立覆盖。
- 导航测试额外覆盖字号重排期间挂起并稳定位置。
- 两版工作台浏览器实测：前后翻页归顶，跨页搜索将匹配行定位到可见区域。

`tools/check-reader-navigation.mjs` 为可重复运行的生产浏览器验证脚本。设置 `FURIGANA_TEST_URL` 为本地生产服务 URL；可通过 `PLAYWRIGHT_MODULE` 指定外部 Playwright 模块，通过 `CHROMIUM_EXECUTABLE` 指定浏览器。音量键桥在浏览器中采用 mock，验证页面启停和事件链路。

**限制：** `adb devices` 无连接设备，因此尚未在 Android 真机或模拟器上验证实体音量上／下、长按、系统音量 UI 与应用焦点的实际行为；编译通过及浏览器桥接验证不等于实体按键验证。未增加 iOS 音量键支持。
