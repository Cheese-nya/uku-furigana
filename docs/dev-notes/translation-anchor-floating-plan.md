# 翻译切换位置保持与悬浮开关

2026-11-08 用户确认；普通版与独立云版同步实施。

- 保持阅读视口上方第一句完整原文及屏幕偏移；无完整可见句时使用可见原文字符作为后备，不能跳回长段开头。
- 翻译开关与异步译文、失败重试引起的重排均做无动画位置补偿；横排和竖排都支持。
- 用户正在触摸、滑动或惯性滚动时缓存新译文，停稳后合并显示；主动滚动更新锚点，不能拉回旧位置。
- 长按底栏翻译按钮约450ms后拖出；仅翻译图标的圆形按钮（可见圆面36px，透明触控范围44px，无常态描边）；状态仅以明暗表示，开启亮、关闭暗，无可见开／关文字（用户后续调整），自由停放，不吸边。
- 悬浮后移除底栏重复按钮；收回后恢复。一次拖动结束不能触发翻译开关。
- 本设备跨书、重启记忆悬浮状态，横竖屏分别保存位置；位置限制在安全区内，屏幕尺寸变化后保持可操作。
- 拖动时显示底部“放回工具栏”区域；排版设置也提供收回与非拖动入口。
- 悬浮入口在沉浸阅读中保留；设置等模态界面出现时临时隐藏。支持键盘及减少动态效果。

验收：同一原文位置在开关和译文更新后尽量保持（滚动边界允许夹取）；快速开关、长段、横竖排、切书、缓存/乱序译文、惯性滚动、拖动取消、重启位置记忆与收回均覆盖。
